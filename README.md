# 微信公众号排版编辑器

一个单文件、离线可用的微信公众号排版工具，无需安装，双击即可使用。

## 在线使用

👉 [https://aprilxuu.github.io/wechat-editor/](https://aprilxuu.github.io/wechat-editor/)

## 本地使用

1. 下载 `index.html`
2. 双击在浏览器中打开
3. 开始排版！

## 功能特点

- **完全离线**：单文件 HTML，无需服务器
- **数据本地存储**：使用 IndexedDB，隐私安全
- **一键排版**：自动应用样式
- **文档管理**：多文档切换、重命名、删除
- **模板系统**：保存和加载排版模板
- **图片处理**：裁剪、缩放、圆角、删除
- **标题样式**：竖线、主题色
- **颜色系统**：自定义主题色、保存颜色方案
- **手机预览**：模拟手机视图效果

## 技术特点

- 单文件 HTML（~160KB）
- 无外部依赖
- 支持 IndexedDB 存储
- 支持 localStorage 配置
- 响应式设计

## 使用方式

### 在线版本
直接访问：https://aprilxuu.github.io/wechat-editor/

### 本地版本
```bash
git clone https://github.com/Aprilxuu/wechat-editor.git
cd wechat-editor
# 双击 index.html
```
